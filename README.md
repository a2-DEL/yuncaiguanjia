不同于传统财务软件仅服务会计、通用 AI 工具无合规约束的短板，云财管家基于 **「一套数据底座、三层角色视图、人机双动力模式」**，打造适配小微企业的全员业财协作体系，覆盖业务记账、财务审核、老板经营管控全流程，兼顾 **数据隐私、财务合规、经营决策** 三大核心需求。

---

## 📌 行业痛点与项目背景

当前小微企业财务数字化普遍存在四大核心痛点：

- **角色割裂**：传统财务软件单一会计界面，老板看不懂经营数据、业务不会记账、财务操作繁琐，全员无法协同；
- **AI 鸡肋化**：主流财务软件 AI 为附加插件，通用 AI 工具无财务内控约束，权责模糊、易乱账、无审计追溯；
- **数据不安全**：金蝶、用友等云端财务系统，财务核心数据存储于厂商云端，小微企业数据隐私无保障；
- **业财脱节**：业务流水无法快速转化为财务凭证，记账门槛高、错账漏账频发，无常态化风险预警机制。

针对以上痛点，云财管家摒弃「会计专属记账工具」的传统定位，打造 **全员可用、合规可控、数据自主** 的新一代 AI 财务经营系统。

---

## 🚀 核心差异化优势

对比传统财务软件、个人记账工具、通用 AI 财务产品，核心差异化壁垒：

| 对比维度 | 传统云端财务软件<br/>（金蝶/用友） | 个人记账工具<br/>（随手记等） | 通用 AI 财务工具 | **云财管家** |
|---|---|---|---|---|
| 产品定位 | 专业会计记账工具 | 个人流水记录工具 | 通用 AI 问答工具 | **全员业财经营协作系统** |
| 角色体系 | 单一会计视角，无角色区分 | 无企业角色体系 | 无角色权限管控 | **三层原生角色视图（老板/财务/业务）** |
| AI 能力模式 | 可选插件，无岗位适配 | 无 AI 能力 | 权责模糊，无内控约束 | **6 大岗位化 AI 数字员工，权限贴合财务内控** |
| 系统可用性 | 依赖 AI，无 AI 基础功能残缺 | 仅基础记账，无经营分析 | 无 AI 则完全失效 | **人机双动力：无 AI 也可完整做账，AI 为增效工具** |
| 数据存储 | 厂商云端存储，数据托管 | 厂商云端存储 | 云端传输，数据泄露风险高 | **本地 IndexedDB 存储，数据不出设备，隐私可控** |
| 合规审计 | 厂商后端审计，用户不可自主校验 | 无审计体系 | 无审计追溯能力 | **SHA-256 哈希审计链，本地全程可追溯校验** |
| 业财协同 | 需额外购买协同模块，成本高 | 无企业协同能力 | 无协同流程 | **业务自然语言记账 + 财务审批闭环，无缝协同** |

## 🏗️ 核心架构设计

项目采用 **「一底座、三视图、双驱动、强内控」** 的分层架构，兼顾稳定性、安全性、可扩展性：

### 1. 统一数据底座（核心基石）

基于 **IndexedDB + Dexie** 构建本地私有数据底座，统一存储凭证、会计科目、财务报表、经营数据，搭配 **SHA-256 哈希审计链**，实现所有财务操作全程留痕、不可篡改、本地可校验，彻底解决小微企业财务数据合规与隐私痛点。

### 2. 三层角色隔离视图（业务核心）

同一套数据底座，差异化渲染三类用户交互界面，解决全员协同痛点：

- **老板驾驶舱**：轻量化经营视图，聚焦现金流、利润、风险预警、经营预测，无需财务专业知识即可看懂企业经营状况；
- **财务工作台**：专业化操作视图，聚焦凭证审核、账目核对、税务处理、AI 提案审批，贴合财务内控流程；
- **业务快捷入口**：极简操作视图，支持自然语言记账，零财务门槛完成业务流水录入。

### 3. 岗位化 AI Agent 团队（智能核心）

独创 **6 大财务岗位数字员工**，严格遵循财务 **不相容职务分离** 内控原则，AI 权限完全对标人工岗位，杜绝越权操作：

| Agent | 岗位 | 权限边界 | 职责 |
|---|---|---|---|
| `bookkeeper` | 记账专员 | 可写·待批 | 批量生成凭证草稿，仅可提交待批，无直接入账权限 |
| `auditor` | 审核主管 | 只读·建议 | 全量账目扫描，识别错账、科目误用、异常数据，仅建议不修改 |
| `cashier` | 出纳专员 | 可写·待批 | 银行流水自动匹配、登账，仅限出纳相关业务 |
| `taxer` | 税务专员 | 只读·建议 | 自动计税、提醒免税临界点，规避税务风险 |
| `watcher` | 经营参谋 | 只读·建议 | 现金流风险预警、经营沙盘模拟，辅助决策 |
| `reporter` | 报表参谋 | 只读·建议 | 经营数据归因分析、自动生成月度经营简报 |

### 4. 人审闸门内控机制（合规核心）

所有 AI 输出结果均为 **待审批提案（Proposal）**，不直接修改账目，形成 「AI 生成 → 人工审核 → 合规入账」 闭环，支持 **全自动 / 待批 / 仅建议** 三档强度，平衡效率与合规性。

## ✨ 核心功能与业务场景

### 1. 老板经营决策体系（解决「看不懂、不会管」）

整合核心经营指标（可动用资金、月度利润、现金最低点、毛利率），支持 **30 天现金流预测、经营风险预警、What-If 沙盘模拟**（成本上涨、回款延迟等场景推演），支持自然语言问答、一键导出经营简报，助力老板快速掌握企业经营风险与盈利状况。

### 2. 零门槛业务记账（解决「业务不会记账」）

独创 **自然语言记账** 能力，业务人员只需输入日常话术，系统自动转化为标准会计分录，覆盖费用报销、采购、销售、回款等高频场景，彻底消除业财脱节问题。

| 你说 | 系统自动生成 |
|---|---|
| 打车 86 微信付 | 借：交通费 86 / 贷：微信 86 |
| 进货 5000 未付款 | 借：库存商品 5000 / 贷：应付账款 5000 |
| 客户转了 8000 | 借：银行 8000 / 贷：收入 8000 |
| 卖给客户 5000 未收款 | 借：应收账款 5000 / 贷：收入 5000 |

### 3. 常态化智能体检（解决「错账漏账、风险滞后」）

系统每周自动调度 AI 团队完成全维度财务体检，串联出纳核对、账目审核、税务校验、经营诊断，自动生成异常提案并推送至负责人，实现 **财务风险前置预警**。

### 4. 轻量化移动端 PWA（解决「随时随地办公」）

支持手机桌面快捷安装，集成 **数据查看、智能问答、快捷记账、待办审批** 四大核心能力，满足移动化、碎片化办公需求。

## 🚀 快速部署上手

### 环境依赖

Node.js 16+ / npm

### 部署命令

```bash
# 克隆项目
git clone https://github.com/a2-DEL/yuncaiguanjia.git
cd yuncaiguanjia

# 安装依赖
npm install

# 启动本地开发服务
npm run dev
# → http://localhost:5173

# 生产打包
npm run build
```
