# 云财管家 · AI 全员业财协同系统

> 本地优先、岗位化 AI 驱动的小微企业业财经营系统。一套账本，三层角色视图，人机双动力。

[![React](https://img.shields.io/badge/React-18-61dafb?logo=react&logoColor=white)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Vite-5-646cff?logo=vite&logoColor=white)](https://vitejs.dev/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#-license)

云财管家不是会计专用记账软件附加 AI 插件，而是面向 **老板、财务、业务全员** 的经营协作系统。所有财务数据保存在浏览器本地 IndexedDB，数据不出设备；内置 **6 个岗位隔离 AI 数字员工**，遵循财务内控不相容职务分离，AI 生成提案，人工审批后入账。

---

## ✨ 核心亮点

- 👔 **三层原生视图**：同一套账本，老板驾驶舱 / 财务工作台 / 业务快捷入口，不同人看到不同界面
- 🤖 **岗位化 AI Agent 团队**：6 个数字员工，权限严格匹配岗位，AI 不能直接改账，全部走 Proposal 人工审批闸门
- 🔒 **本地优先隐私底座**：IndexedDB + Dexie 存储，SHA-256 哈希审计链，操作全程留痕、本地可校验
- 🧠 **人机双动力**：不启用 AI 也可以完整做账；AI 仅作为增效助手，可按需开关
- 📱 **PWA 移动端**，手机桌面直接安装，随时记账、审批、看经营数据


## 🎯 适合谁 & 解决什么问题

**目标用户**：小微企业、创业团队、个体工商户

传统财务软件普遍痛点：

- 一套会计界面给所有人，老板看不懂报表，业务人员不会做分录
- AI 只是附加插件，权限无管控，容易乱账，缺少审计追溯
- 财务数据托管在厂商云端，敏感经营数据存在外泄风险
- 业务单据到会计凭证转换成本高，业财脱节，风险发现滞后

**云财管家方案**：业务人员用自然语言录入业务流水 → AI 翻译成会计分录生成提案 → 财务审核入账 → 老板在驾驶舱看现金流、利润、风险预警。

## 🧩 核心能力

### 👔 老板驾驶舱

一键查看可动用资金、月度利润、现金流最低点、毛利率；30 天现金流预测、风险预警；What-If 经营沙盘模拟；自然语言问答，一键导出经营简报 PDF。

### 💬 业务端一句话记账

业务人员不需要懂会计，直接用自然语言描述业务，系统自动生成会计分录：

```
打车 86，微信支付        →  借：交通费 86 ｜ 贷：微信 86
进货 5000，尚未付款      →  借：库存商品 5000 ｜ 贷：应付账款 5000
客户转来 8000 到银行卡   →  借：银行 8000 ｜ 贷：收入 8000
```

### 🤖 岗位化 AI Agent（内控隔离）

所有 AI 输出均为待审批提案 Proposal，AI 无权直接修改账本：

| Agent | 权限边界 | 职责 |
|---|---|---|
| 记账专员 | 可写・待批 | 批量生成凭证草稿 |
| 审核主管 | 只读・建议 | 扫描账目，识别错账、科目异常 |
| 出纳专员 | 可写・待批 | 银行流水匹配、出纳登账 |
| 税务专员 | 只读・建议 | 计税、小规模免税线提醒 |
| 经营参谋 | 只读・建议 | 现金流预警、经营沙盘推演 |
| 报表参谋 | 只读・建议 | 经营归因、月度简报生成 |

> **内控铁律**：不相容岗位隔离，AI 权限等同于同岗位人工权限。

### 🩺 周度智能体检调度器

自动调度 AI 团队定期巡检账目，自动识别异常，生成提案推送负责人，全程写入哈希审计日志。

### 📱 PWA 移动端

4 个 Tab：看资金、自然语言问答、快速记账、审批待办，可添加到手机桌面。

## ⚖️ 差异化对比

- **传统云端财务软件（金蝶/用友）**：面向会计，数据厂商托管，AI 为附加插件，角色视图单一；额外付费才能做业务协同。
- **个人记账工具（随手记）**：仅个人流水，无企业会计科目、凭证、内控。
- **通用 AI 聊天财务工具**：权责无管控，AI 直接改账，无审计链，无角色权限。
- **云财管家**：全员业财协同，三层角色视图；本地数据 + SHA-256 审计链；岗位隔离 AI；**无 AI 也可独立完整做账**。

## 🧱 技术栈

- **框架**：React 18 + TypeScript
- **构建**：Vite 5
- **UI**：Ant Design 5 + Tailwind CSS
- **状态**：Zustand
- **本地数据库**：Dexie + IndexedDB
- **图表**：Recharts
- **AI 层**：OpenAI 兼容协议，支持 DeepSeek / 豆包 / 通义 / 智谱，用户自备 API Key

> 架构特点：前端单页应用，零后端服务，全部业务与数据存储在客户端浏览器。

## ❓ FAQ

**Q：数据保存在浏览器，换电脑会丢失吗？**
> A：支持加密备份导出文件，可在新设备导入恢复数据。

**Q：AI 密钥会上传到你的服务器吗？**
> A：不会。API Key 保存在你的浏览器本地，直接向大模型厂商接口请求，不经过中间服务器。

**Q：可以用来做税务申报、对外报税吗？**
> A：本系统定位为内部经营业财管理系统，用于企业内部经营核算，不直接替代外部报税系统。

**Q：不配置大模型 API，系统还能用吗？**
> A：可以。全部财务基础功能完整可用，AI 仅作为可选增效模块。
